## 使用定向传送门快速传送的常见问题

### 1.传送需要准备什么？

答：需要准备任意颜色的定向传送门，带有目标位置的锁定地图，如果传输距离很远可能需要准备充足的经验

​     

### 2.传送需要消耗多少经验？

答：2000格曼哈顿距离内传送不消耗经验，超过2000格曼哈顿距离会消耗一定的经验，这边放一张表格

| 距离（单位：曼哈顿距离） | 消耗经验等级 |
| ------------------------ | ------------ |
| 0~2000                   | 0            |
| 3000                     | 4            |
| 4000                     | 6            |
| 5000                     | 8            |
| 10000                    | 14           |
| 20000                    | 20           |

​     

### 3.传送后多久才能再次传送？

答：默认传送冷却为15秒

​     

### 4.在别的维度可以传送吗？

答：只能在主世界传送，其他维度禁用
