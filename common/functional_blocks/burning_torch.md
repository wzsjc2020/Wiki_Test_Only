​     

| 添加此物品的原因 | 李芒果空岛前期缺少夜间光源，树苗无法生长 |
| :--------------- | :--------------------------------------- |
| 稀有度           | 常见                                     |
| 命名空间         | comfysky:burning_torch                   |
| 添加版本         | 17.1.15                                  |

​     

## 获取

手持木棍右键一个燃烧的简易篝火获得

​     

## 用途

### 光源

临时性光源，在点燃时发出14格强度的方块光

​     

## 交互

1.当方块被破坏时，燃烧值将保存到物品NBT中

2.可以放置在完整方块上方

3.可以放置在完整方块侧面

​     

## 数值表

| 常量              | 数据  | 数据类型 |
| :---------------- | ----- | -------- |
| @MAX_BURNING_TIME | 24000 | long     |
