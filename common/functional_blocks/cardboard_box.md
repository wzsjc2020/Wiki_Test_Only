# 瓦楞纸箱

<div align=center><img src=../../resources/icon/cardboard_box-128px.png></div>

​     

| 添加此物品的原因 | 李芒果空岛需要可以储存大量物品的容器 |
| :--------------- | :----------------------------------- |
| 稀有度           | 常见                                 |
| 命名空间         | comfysky:cardboard_box               |
| 添加版本         | 17.1.15                              |

​     

## 获取

工作台合成

​     

## 用途

快速打包一整箱物品，像潜影盒一样带走它

​     

## 交互

1.**打包带**shift+右键**瓦楞纸箱**转化为**打包过的瓦楞纸箱**

注意：打包时瓦楞纸箱物品列表中带有#packing_black_list物品标签的物品会导致打包失败

2.使用任意类型的剑（minecraft:sword）挖掘时，挖掘速度翻倍

​

## 你知道吗

1.当玩家试图尝试打包含有packing_blacklist标签物品的瓦楞纸箱时会弹出红色警告 **禁止套娃**

2.在1.20.1版本之前可以使用打包带打包木桶，但是由于木桶会导致村民意外的绑定职业，所以作者在17.1.15版本加入了瓦楞纸箱，同时让竹子变得更有用了XD
