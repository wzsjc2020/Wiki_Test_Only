# 打包过的瓦楞纸箱

<div align=center><img src=../../resources/icon/packed_cardboard_box-128px.png></div>

​     

| 添加此物品的原因 | 李芒果空岛需要可以储存大量物品的容器 |
| :--------------- | :----------------------------------- |
| 稀有度           | 常见                                 |
| 命名空间         | comfysky:packed_cardboard_box        |
| 添加版本         | 17.1.15                              |

​     

## 获取

使用打包带Shift+右键瓦楞纸箱

​     

## 用途

快速打包一整箱物品，像潜影盒一样带走它

​     

## 交互

1.**打包带**shift+右键**瓦楞纸箱**转化为**打包过的瓦楞纸箱**

注意：打包时瓦楞纸箱物品列表中带有#packing_black_list物品标签的物品会导致打包失败

2.带有#packing_blacklist物品标签的物品无法通过漏斗传入此容器

3.使用任意类型的剑（minecraft:sword）挖掘时，挖掘速度翻倍

4.不能放入潜影盒内

​
