## 用途

### 显示当前和 预测未来5分钟的天气

当玩家放置在背包，且**处在主世界**时，晴雨表可以预测未来5分钟游戏的天气

一共有4种天气可以被预测:

| 天气                                                    |
| ------------------------------------------------------- |
| 晴天(clear)![](../../resources/image/clear_32x.png)     |
| 下雨(rain)![](../../resources/image/rain_32x.png)       |
| 下雪(snow)![](../../resources/image/snow_32x.png)       |
| 雷暴(thunder)![](../../resources/image/thunder_32x.png) |

​
